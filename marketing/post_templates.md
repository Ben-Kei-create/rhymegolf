# 投稿の雛形(AI がアプリごとに埋めて下書きを作る)

`【】` を埋める。1投稿=1メッセージ。実在する機能だけ。文字数は X の画面で確認する。

## A. TestFlight テスター募集
```
【困りごと/驚き】
【アプリの一言】を作っています。

テストしてくれる方を【人数】人ほど募集します🙏
期間:【1〜2週間】
見てほしい点:【1〜2個】

▶ TestFlight:【公開リンク】
感想は返信かDMでぜひ。

#TestFlight #個人開発 #【ジャンルのタグ】
```

## B. 開発ログ・チラ見せ
```
【今日やったこと/決めたこと(1つ)】
【理由や迷い(1行)】

【画像:画面】
どっちがいい?A / B

#個人開発 #iOSアプリ
```

## C. リリース前の告知
```
【日付】に【アプリ名】を出します。
【誰向けの、どんな価値(1行)】

【画像:代表画面】
#個人開発 #iOSアプリ
```

## D. ローンチ(リリース日)
```
【アプリ名】、リリースしました。
【一言の価値】

・【特徴1(実在)】
・【特徴2(実在)】

▶ App Store:【URL】
【画像/動画】

#iOSアプリ #リリースしました #【ジャンルのタグ】
```

## E. リリース後
- 使い方の小ネタ: 「【アプリ名】の【機能】、【こう使うと便利】」+画面
- アップデート: 「v【番号】:【直したこと】。【テスターの声】がきっかけです」
- 感謝と返信: 「感想ありがとうございます。【反映したこと/次にやること】」

## 返信の型
- 感想: 感謝 + 具体的に受け取った点 + 次の予定(約束しすぎない)
- 不具合の報告: 感謝 + 状況の確認(機種・iOS) + 対応の見込み
- 批判: 事実を確認 + 受け止める + 直す/直さない理由を短く。感情的に返さない
