# 起動時アニメーション

## 実装の順序(重要)
- 起動時アニメーションは、**他の実装が全て済んでから**、実装の最後の工程として作る。途中で作り込まない(時間の無駄になる)。
- それまでは、静止画1枚(または文字だけ)の仮の起動画面にしておく。
- 「実装完了」には、この起動アニメーションを含める。Archive・アップロードは、これが終わり、オーナーが実装完了を宣言してから。
- 画像の指示プロンプト(下記)は、主要機能が固まった時点(段階2の終わり)に出してよい。オーナーが画像を準備する時間を作るため。

## 再利用を避ける(なるべく)
- アプリアイコンの図柄を、起動アニメーションに流用しない。
- アプリ内の他の場所で使っているアニメーション・演出・素材を、起動アニメーションに使い回さない。逆も同じ。
- 自分の他のアプリの起動アニメーション・演出を、そのまま使い回さない(同型・テンプレートに見え、4.3 / 4.2.6 の観点でも不利)。
- 同じ動きを複数の場所で使う必要がある時は、理由を一行で書き、見た目を変える(色、タイミング、構図)。
- 部品(タイマーやフレーム切り替えのコード)の共通化は構わない。避けるのは、見た目・素材・動きの使い回し。

## 入れる情報(必要なものだけ)
- アプリ名(タイトル)
- 必要な場合のみ: 一言のコピー、対象年齢の注記(アルコールなど)、ロゴ
- 入れないもの: 広告、バージョン番号、長い説明、読み込み中の余計な文言
- 文字は画像に焼き込まず、**コードで描く**(フォントは `philosophy/fonts.md`)。日本語の崩れを防ぎ、差し替えを楽にする。

## 既定の演出(指示がなければこれ)
**パラパラ漫画方式**: 静止画を数枚(4〜6枚)、順番に切り替えて流す。最後のフレームでタイトルを表示して終わる。
- 1枚あたり 0.15〜0.4秒。全体で 2秒前後、長くても 3秒以内。
- 画像は事前に読み込んでおく(切り替えで途切れない)。
- データの読み込みなどは裏で並行して行い、アニメーションのために待たせない。
- **タップでスキップ**できる。
- 「視差効果を減らす(Reduce Motion)」がオンの人には、最後のフレーム(タイトル)を静止で表示する。
- 毎回流すか、初回だけにするかは、Rule mode と体験に合わせて決める(迷ったら毎回、2秒以内)。
- 指示がある場合(別の演出、Lottie、スプライト、3D など)は、その指示に従う。

## OS の起動画面(Launch Screen)との関係
- OS が最初に出す起動画面(Launch Screen)は、アニメーションしない静止の画面にする。アプリ名や背景色など、最後のフレームに近い見た目にしておくと、つながって見える。
- パラパラ漫画は、その直後にアプリ内の最初の画面として流す。

## 画像の指示プロンプト(ChatGPT 用)の出し方
AI は、次の形で出力する。系統(A/B/C)、Era / Voice mode、基本色、アイコンのモチーフと揃える。

1. **土台のプロンプト(1回目)**: 1枚目を作る。世界観、構図、色、質感、サイズ、禁止事項を書く。
2. **差分のプロンプト(2枚目以降)**: 「直前の画像と同じ構図・色・質感のまま、〇〇だけを変える」と指示する。動きは小さく、連続して見えるようにする。
3. **最後のフレーム**: タイトルの文字は入れない(コードで載せる)。タイトルを置く余白を残す。

### 共通条件(必ず入れる)
- 全フレームで、画面サイズ・構図・色・質感・線の太さを揃える。
- サイズ: 縦長の全画面(約 9:19.5、@3x で 1290×2796 px 前後)。端が切れても成立する図柄にする。
- 中央のタイトル位置と、上下の安全領域は、図柄を置かない。
- 文字は入れない。
- 既存のブランド・キャラクターに似せない。
- 動きは、1フレームごとに少しだけ(例: 形が少し伸びる、点が増える、位置が少しずれる)。

### 出力の形式
```
【起動アニメ:全N枚、1枚あたり〇秒、合計〇秒】
動きの概要:(一行)

【フレーム1】ファイル名:launch_01.png
(土台のプロンプト)

【フレーム2】ファイル名:launch_02.png
(差分のプロンプト:「直前と同じ構図のまま、〇〇だけ変える」)

…

【最終フレーム】ファイル名:launch_0N.png
(タイトルを置く余白を残す)
```
`docs/asset_list.md` に、フレームを素材として記録する。

## 実装の指針(iOS / SwiftUI)
- 画像は `Assets.xcassets` に入れ、起動時に先読みする。
- 切り替えは、`TimelineView` やタイマーで、フレーム番号を進める。
- タイトルは `Text` で重ね、最後のフレームでフェードインさせてもよい。
- Reduce Motion: `@Environment(\.accessibilityReduceMotion)` を見て、最後のフレームを静止で表示する。
- スキップ: 画面全体のタップで、最初の画面へ進む。
- 容量: フレームの合計サイズを確認し、大きければ圧縮する(JPEG/HEIC、縮小)。

## 確認項目
- [ ] 総時間が3秒以内。タップでスキップできる
- [ ] Reduce Motion で静止表示になる
- [ ] データの読み込みを待たせていない
- [ ] 文字(タイトル)はコードで描き、固定フォントを使っている
- [ ] OS の起動画面と、最初のフレームが不自然にずれていない
- [ ] 画像の容量が重すぎない
