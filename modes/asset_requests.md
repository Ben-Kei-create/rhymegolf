# 画像素材の依頼(ChatGPT で作る画像を、AI が都度指示する)

コードだけの UI(色、文字、ボタン)では出せない質感や世界観は、画像で補う。
AI は、必要になった時点で、**ChatGPT に渡すプロンプト・サイズ・形式・保存名・使う場所**をセットで指示する。
オーナーは、その指示どおりに画像を作って、指定の場所に置く。AI は画像の生成・加工をしない。

## 素材ごとの作り方(担当ツール)
| 素材 | 作るもの |
|---|---|
| 背景、テクスチャ、質感、イラスト、バッジ、空の状態などの2D画像 | **ChatGPT**(基本はこれ。テクスチャも ChatGPT) |
| 3Dオブジェクト | **Blender** で作る。または **Claude** が Blender の Python スクリプト(bpy)やコードで作る。または他サイトの素材を使う |
| 単純な図形・アイコン的なもの | コードで描く(素材にしない) |

- 3Dオブジェクトの表面の模様(テクスチャ)は、ChatGPT で作り、3Dに貼る。
- Claude が作れるのは、コードで表現できるもの(手続き的なモデル、スクリプト)。AI は Blender 本体の操作や画像の生成はできない。実行・書き出しはオーナーが行う。
- 他サイトの素材は、使う前に**ライセンスを必ず確認**する(商用利用可否、クレジット表記の要否、再配布の可否)。確認できないものは使わない。出典とライセンスを `docs/asset_list.md` に残す。

## 再利用を避ける(なるべく)
- アプリアイコンの図柄や、アプリ内に出てくるアニメーション・演出を、別の場所に使い回さない。素材は、場面ごとに新しく依頼する。
- 自分の他のアプリの素材・アニメーションも、そのまま使い回さない(同型に見えるため)。
- 共通化してよいのは、コードの部品。見た目・素材・動きは、アプリごと・場面ごとに変える。

## 依頼する場面(コードだけでは品質が足りない所)
- 全体の背景(画面全体の質感、グラデーション、模様)
- 紙・布・木などの質感、パネルやカードの面
- ボタンや枠の装飾(押した感じ、縁取り、スタンプ風など)
- 空の状態(データがない画面)、エラー、読み込み中のイラスト
- 結果・ランクなどのバッジ、ステッカー、象徴的なモチーフ
- 起動画面、ホームの主役ビジュアル
- ストアのスクリーンショット用の背景(必要な時のみ)
- 起動時アニメーションのフレーム画像(`modes/launch_animation.md`。実装の最後に作る)

画像を足さない方がよい所: 文字、アイコン的な単純な形、色面だけで足りる所(コードで描く方が軽く、崩れない)。
思想「機能は削る。体験は削らない」に従い、**効果が大きい所に絞る**。点数が多くなったら、減らす案を出す。

## 依頼の形式(1点ごとに、必ずこの形で出す)
```
【素材 N:名前】 使う場所:〇〇画面の〇〇
- ファイル名:bg_home.png(英小文字・数字・アンダースコア)
- サイズ:〇〇×〇〇 px(@3x 想定。@2x/@1x は後で縮小)
- 形式:PNG(透過が必要)/ JPEG・HEIC(写真的な背景。容量を小さく)
- 透過:要 / 不要
- 向き・余白:縦長。上下〇〇%に主要な図柄を置かない(文字やボタンが載る)
- ライト/ダーク:共通 / 別々に作る
- ChatGPT に貼るプロンプト:
  (日本語。下の共通条件を含める)
- 置く場所:Assets.xcassets / 〇〇.imageset(または docs/assets/〇〇)
```

## 3Dオブジェクトの依頼形式
```
【3D N:名前】 使う場所:〇〇画面の〇〇 / 作り方:Blender / Claude(スクリプト)/ 他サイト
- 書き出し形式:iOS(SceneKit/RealityKit)は USDZ、Godot は glTF(.glb)を基本にする。使うエンジンに合わせる
- 大きさ・向き:単位はメートル。原点は足元(または中心)。正面は〇〇方向
- ポリゴン数の目安:〇〇以下(スマホで軽く動くこと)
- テクスチャ:ChatGPT で作る(別途【素材】として、サイズ・プロンプトを指示)。解像度は 1024〜2048 px の正方形を基本に
- アニメーション:なし / あり(内容)
- 置く場所:Assets.scnassets など
```

## サイズの考え方
- 画面全体の背景: 縦長(約 9:19.5)。@3x で 1290×2796 px 前後を基準にし、端が切れても成立する図柄にする。デバイスの実サイズは Xcode で確認する。
- タイル状の模様: 継ぎ目が出ない(シームレス)ように指示する。正方形(例 512×512 px)。
- ボタン・バッジ・イラスト: 実際の表示サイズの3倍で指示する(例: 表示 120pt → 360 px)。
- 数や容量が増えると、アプリが重くなる。背景は JPEG/HEIC で圧縮し、合計の容量を確認する。

## プロンプトに必ず入れる共通条件
- 系統(A/B/C)、Era / Voice mode、基本色(16進数)に合わせる。全素材で統一する。
- 文字を入れない(入れるなら読める短い語のみ)。文字はコードで描く。
- 既存のブランド、ロゴ、キャラクターに似せない。
- 画面上に載る文字・ボタンの邪魔にならない、落ち着いた濃淡にする。
- 透過が必要な場合は、背景を単色の平らな色にして、あとで抜きやすくする(ChatGPT が透過PNGを出せない場合に備える)。
- 簡素でも安っぽくしない。細部を詰めすぎず、統一感を優先する。

## 記録と確認
- 依頼した素材は `docs/asset_list.md` に一覧にする(名前、サイズ、置き場所、状態:依頼/受領/組込済)。
- 受け取った画像は、AI がサイズ・形式・容量・命名を確認し、問題があれば作り直しの指示を出す。
- ストア用・公開ページ用の画像は、`appstore/screenshots.md` と `web/README.md` に従う。
- 出所を残す(どのツールで作ったか)。第三者の素材は、出典とライセンスも記録する。
